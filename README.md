## Описание

Сворачиваемый/разворачиваемый контейнер на чистом JavaScript (аналог Bootstrap Collapse без jQuery).

## Установка и запуск

```bash
npm install
npm start      # localhost:9000
npm run build  # production
```

## Технологии

- JavaScript (ES6+)
- Webpack 5
- CSS3 анимации
